---
title: Quick Start
---

To get started with Dittofeed, you'll need do the following:

1. Deploy Dittofeed. You can self-host or use our [cloud offering](/deployment/cloud).
2. Send Dittofeed your user data.
3. Integrate a messaging channel.
4. Create a user journey.

You can self-host with Docker Compose and ingest user data through Dittofeed's
REST API or native SDKs. Configure an email provider such as SendGrid to send messages.
